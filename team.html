The problem

Five phones can accidentally become five jobs

Sayt merges visits into a project by its id. A crew's visits only come back into one job if everyone's copy of that job shares the same id.

Before Team mode, the supervisor had to export the project file and send it round before anyone started. Miss that step and five people could produce five separate jobs. Those visits could not be reported on together.

Team mode gives the crew one shared id without sending a project file first.

Team codes

The code is the job

The supervisor picks words the crew can remember, for example sayteam 1. Everyone opens Project Settings and types the same words.

The same words resolve to the same job on every device, offline. Nothing is shared except the words themselves. The code is never sent anywhere. It is hashed on the device.

  • No server
  • No account
  • No sign-up
  • Nothing uploaded
  • Minimum 4 characters
  • Works across iPhone and Android

Case and punctuation do not matter. Sayteam 1, sayteam-1 and SAYTEAM 1 are one job.

Sending a visit in

Each person records the visit as normal

The engineer, architect, QA/QC checker or supervisor walks the site on their own phone. Photos, observations, issues, measurements and plan pins are recorded the usual way.

When the visit is ready, they share a .saytpack handoff file. Use AirDrop, email, WhatsApp, Drive or whatever the site already uses. The supervisor opens the file in Sayt and the visit lands in the shared job, tagged with who sent it.

Importing a handoff file is a Sayt Pro feature.

Group reports

One report for the crew's work

Pick a week or any date range. Sayt builds one report spanning all the visits in that period.

In a group report, every observation and every issue says who recorded it. The reader can see which engineer, architect, checker or supervisor saw each item.

A solo report does not repeat the name on every card, because the name is already on the letterhead.

  • Weekly reports for this week, last week or any week you choose
  • Custom-range reports for any start and end date
  • Every visit in the range, renumbered into one document
  • Every observation and issue labelled with the person who recorded it
  • The same report templates and preview used for solo visits

Free users get ten weekly reports and ten custom-range reports. Sayt Pro removes the limit.

Local-first

Team mode does not add a backend

Sayt stays offline. There is no shared cloud workspace, no login and no dashboard. The team code is hashed on each phone. Visits move only when a person chooses to share a .saytpack file.

That is why it still works in basements, plant rooms, rural sites and any job where signal is bad.
